## 2026-06-08 - FodselsnummerValidator Optimization
**Observation:** The legacy validation algorithm performed numerous string splits, regular expression matches, and parsing of substrings which caused large GC pressure (2584 B allocated) and slow latency (2.98 us) on full validation passes including checksums.
**Strategic Action:** Substituted string segmentation and regex with `ReadOnlySpan<char>` slicing and stackalloc index-based parsing. Used manual integer subtraction instead of `int.Parse` avoiding internal allocations. Documented Big O time/space complexity (O(1)). Reduced mean execution time to 718.6 ns, and memory allocation to 816 B. This was implemented while maintaining full `netstandard1.2` compatibility using conditional compilation without any unauthorized `.csproj` modifications or external dependencies.
