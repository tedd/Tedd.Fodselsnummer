Supported structures

Recognize the encoded
number type.

The validator compensates for the date-field offsets used by D- and H-numbers and recognizes the distinct FH-number prefix before checksum evaluation.

01

Fødselsnummer

Standard national identity number with encoded date, individual sequence, and two control digits.

D

D-nummer

Temporary identity-number structure with 40 added to the encoded day component.

H

H-nummer

Health-institution helper-number structure with 40 added to the encoded month component.

FH

FH-nummer

Shared health helper-number structure identified by an initial digit of eight or nine.

Deterministic validation

Reject malformed input at the precise stage.

The result distinguishes length, digit, individual-range, year-range, date, and checksum failures. Successful ordinary, D-, and H-number parsing also resolves the encoded birth date and gender field.

Structural validation only. A valid format and checksum do not establish that a number was issued, remains active, or belongs to a particular person.

Explicit result object

Success, classification,
or a specific error.

FodselsnummerResult carries the validation state, error code and message, classified type, and decoded fields where the format provides them.

Program.cs
using Tedd.Fodselsnummer;

FodselsnummerResult result =
    FodselsnummerValidator.Validate(input);

if (!result.Success)
    Console.WriteLine(result.ErrorMessage);
else
    Console.WriteLine($"{result.Type}: {result.Birthday:yyyy-MM-dd}");
